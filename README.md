\# Automation Lab

Personnel automation \& AI integration projects. Building systems, not just tools.



\## Structure

\- \*\*`projects/`\*\* – Completed automation projects with case studies

\- \*\*`scripts/`\*\* – Reusable API helpers \& utilities (Node.js, Python)

\- \*\*`prompts/`\*\* – Prompt engineering templates \& libraries

\- \*\*`workflows/`\*\* – n8n, Make, Zapier exports \& templates

\- \*\*`docs/`\*\* – Documentation, API references, CLAUDE.md



\## Philosophy

\- Process before tools. Map workflows, then automate.

\- Document everything. Every project is a case study.

\- Security first. Never commit API keys.

\- Reusable. Every script, prompt, and workflow is a template for the next client.



\## Current Focus

\- Module 02–04: WordPress, APIs, n8n

\- Target: 10 portfolio projects by month 9
